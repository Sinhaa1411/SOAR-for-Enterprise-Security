“Project focused on understanding Security Orchestration, Automation and Response, or SOAR. I used the
Awesome-SOAR repository as a structured reference because it brings together SOAR standards, incident
categories, incident-response processes, playbooks, automation resources, training and SOAR platforms. I
studied the workflow from security inputs such as SIEM alerts through incident categorization and contextual
analysis, selection of a fully automated, semi-automated or manual playbook, enrichment or escalation, and finally
response. The key takeaway was how SOAR converts repetitive incident-response procedures into standardized
digital workflows while keeping human analysts involved where judgment or approval is required. I also reviewed
resources from ecosystems such as Microsoft Sentinel, Shuffle, TheHive/Cortex, Rapid7, ThreatConnect and
other SOAR technologies. The repository itself is a curated resource project.
